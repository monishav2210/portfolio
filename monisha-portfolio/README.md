# Monisha V Portfolio

A premium, responsive portfolio for Monisha V, built with React, Vite, JavaScript, CSS, React Icons, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Portfolio content lives in `src/data/portfolioData.js`. Add the real resume file under `public/resume/` and configure contact/social URLs there before deployment.
